# 🎨 Color Sorting App

A Streamlit web application that detects the **dominant color** of an uploaded image using **HSV color space**.

---

## 🚀 Live Demo

👉 **Click here to use the app:**  
🔗 https://color-sorting-app-fmibbadmj2nghhsrtsetbh.streamlit.app/

---

## 🧠 Features
- Upload an image (JPG / PNG)
- Detects dominant color (Red, Green, Blue, Yellow, etc.)
- Shows confidence score
- Fast & lightweight (no deep learning in production)

---

## 🛠 Tech Stack
- Python
- Streamlit
- OpenCV
- NumPy
- Pillow

---

## 📦 How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
